# Mixo Supports

**無料の光造形 3D プリント用サポートを、ブラウザだけで。**
モデルをドロップすれば、数秒で印刷できる SLA / MSLA / DLP サポートを生成。手作業で細かく調整し、STL でスライサーへ書き出せます。インストールもアカウントも不要。ファイルがパソコンの外に出ることはありません。

## Mixo Supports の特長

- **どこでも使える。** ブラウザで動作し、Windows、macOS、Linux、ChromeOS、タブレット、スマートフォンに対応。リンクを開くだけで始められます。
- **プライバシー重視。** モデルはお使いの端末上で読み込み・処理されます。アップロードも登録もなく、アクセス解析もありません。
- **実証済みのジオメトリ。** サポート生成は Blender の SLASG / Resin UV サポートシステムと同じ結果になり、実際の Blender 出力とビット単位で照合しています。
- **大きなモデルでも快適。** 重い処理はバックグラウンドのワーカーで実行するのでエディタは滑らかなまま。時間のかかる処理には進捗バーが出ます。
- **無料。** 透かしも有料機能もありません。

## 機能

### 自動サポート
- ワンクリックで **下向きの面**、**アイランド**（空中で印刷されてしまう最下点）、**オーバーハングのエッジ** にサポートを配置。
- **ライト・ミドル・ヘビー** のプリセット、または間隔、オーバーハング角度（既定 50°）、稜線角度、リフト高さ、柱の直径などを自由に設定。
- 枝分かれして合流する **ツリーサポート** で、レジンと剥離力を節約。
- モデルの輪郭に沿った **ラフト**（斜めに広がる壁とオブジェクト文字付き）。**ルーフ** と **ケージ** モードもあります。
- 1 枚のプレートに複数のモデルを配置可能。各モデルは独立したオブジェクトで、サポートはモデルと一緒に移動・回転します。

### よく付いて、きれいに外れる接点
- **既定は円錐の先端**：0.2 mm の先端から柱の太さまで広がるので、接点の跡が小さく済みます。
- 先端の断面は **丸**・**角**・**十字**、先端の形は **テーパー**・**ストレート** から選択。接触形状は **なし** か **球**。
- **食い込み深さ** を調整でき、先端がモデルに少し埋まって印刷中にしっかり結合し、外れません。

### サポート編集モード
![サポート編集モード：赤い枠、キーヒント、完了ボタン](docs/images/edit-mode.png)

- モードに入ったら **クリック** でサポートを追加、**右クリック** で削除。クリック前に半透明のプレビューで結果がわかります。
- 赤い枠とバッジで編集中であることが一目でわかります。**完了** か **Esc** で終了、Tab キーで切り替え。
- **元に戻す / やり直し** に完全対応。手動編集は再生成後も保持され、**手動編集をクリア** で自動配置に戻せます。

### サポートのない箇所を確認
どのサポートも届いていないアイランドやオーバーハングを検出して一覧表示します。**表示** でカメラがその場所へ移動し、**修正** でその場でサポート編集モードが開くので、足りないサポートを追加できます。

### 読み込みと書き出し
- **STL**、**GLB**、**glTF** を読み込み可能。STL はスライサーと同じく Z 軸上向きで読み込みます。
- **STL** を書き出し：選択中のオブジェクトまたは各オブジェクト（モデルあり・なし）、またはプレート全体を 1 ファイルに。
- 書き出したファイルは Chitubox、Lychee、PrusaSlicer、UVtools などの光造形スライサーにそのまま読み込めます。

## 使い方

1. **[mixocreative.github.io/mixo-supports](https://mixocreative.github.io/mixo-supports/)** を開きます。
2. STL、GLB、glTF を **モデルを読み込む** にドロップします。
3. モデルを移動・回転して印刷の向きにします。
4. **サポートを生成** を押し、プリセットを選ぶか設定を調整します。
5. 必要に応じて **サポートのない箇所を確認** を実行するか、**サポート編集モード** で手直しします。
6. STL を **書き出し**、いつも通りスライスします。

## 開発者向け

React、Three.js（react-three-fiber）、TypeScript、Vite、Web Workers。ピッキングに three-mesh-bvh を使用。

```bash
npm install
npm run dev      # ローカルエディタ：http://localhost:5173/mixo-supports/
npm test         # Vitest（Blender との一致テストを含む）
npm run build    # 型チェックと dist/ への本番ビルド
```

`main` へのプッシュごとに GitHub Pages へ自動デプロイされます。コード構成は [英語版 README](README.md#for-developers) をご覧ください。
